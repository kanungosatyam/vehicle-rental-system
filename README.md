# 🚗 Vehicle Rental Management System

A desktop-based **Vehicle Rental Management System** developed in **Java** as part of an Object-Oriented Programming (OOP) project. The application provides an intuitive graphical interface for managing vehicle rentals, customers, vehicle owners, and booking records while demonstrating core OOP concepts such as encapsulation, inheritance, abstraction, and polymorphism.

## ✨ Features

* Secure login system
* Customer management (Add, Update, Remove, View)
* Vehicle owner management
* Vehicle management
* Vehicle booking and return
* Booking history management
* User-friendly Java Swing interface
* Data persistence using Java Serialization

## 🛠️ Technologies Used

* Java
* Java Swing
* Object-Oriented Programming (OOP)
* Java Serialization
* NetBeans IDE
